Laboratório Rundeck + Windows via WinRM

Documento completo para integração de um servidor Rundeck com uma máquina Windows utilizando WinRM.

Arquitetura do Laboratório

┌─────────────────────────────┐ │ Rundeck │ │ │ │ Job: Get-Date │ │ Job: Get-Service │ │ Job: Get-Process │ └──────────────┬──────────────┘ │ │ WinRM HTTP │ TCP/5985 ▼ ┌─────────────────────────────┐ │ Windows VM │ │ │ │ WinRM Enabled │ │ Basic Auth Enabled │ │ AllowUnencrypted = True │ │ User: deivid │ └─────────────────────────────┘

1. Preparando o Windows

Verificar perfil da rede

Get-NetConnectionProfile

O perfil da rede deve estar como Private. Caso esteja como Public, altere: 

Set-NetConnectionProfile `
  -Name "Rede" `
  -NetworkCategory Private

Verificar serviço WinRM

Get-Service WinRM

Iniciar serviço

Start-Service WinRM
Set-Service WinRM -StartupType Automatic

Habilitar PowerShell Remoting

Enable-PSRemoting -Force

Habilitar autenticação Basic

Set-Item WSMan:\localhost\Service\Auth\Basic -Value $true

Permitir tráfego sem criptografia (HTTP 5985)

Set-Item WSMan:\localhost\Service\AllowUnencrypted -Value $true

Reiniciar serviço WinRM

Restart-Service WinRM

Verificar configuração

winrm get winrm/config/service

Resultado esperado:

Basic = true
AllowUnencrypted = true

Verificar Listener

winrm enumerate winrm/config/listener

Verificar porta 5985

netstat -ano | findstr 5985

Liberar Firewall

Enable-NetFirewallRule -DisplayGroup "Windows Remote Management"

2. Testando WinRM a partir do Linux

Validar conectividade TCP

nc -vz 192.168.100.151 5985
Resultado esperado: 
Connection to 192.168.100.151 5985 port [tcp/*] succeeded!

sudo apt update
sudo apt install python3-pip python3.12-venv -y

python3 -m venv .venv
source .venv/bin/activate

pip install pywinrm

Teste Python

import winrm

s = winrm.Session(
    'http://192.168.100.151:5985/wsman',
    auth=('deivid', 'teste')
)

r = s.run_cmd('hostname')

print("STATUS:", r.status_code)
print("STDOUT:", r.std_out)
print("STDERR:", r.std_err)

3. Criando o segredo no Key Storage

Criar a chave:

keys/project/windows-lab/password_user_win

Senha:

teste

4. Configuração do Node

windowsvm:
  nodename: windowsvm
  hostname: 192.168.100.151
  osFamily: windows
  username: deivid
  authType: basic
  winrmPort: '5985'
  winrmTransport: plaintext
  winrm-password-storage-path: keys/projects/windows-lab/password_user_win
  tags: windows

5. Configuração do Projeto Rundeck

  • Node Executor: WinRM
  • Python Interpreter: python3 ou /usr/bin/python3
  • Refresh Nodes após salvar

6. Job de Teste

Get-Date
